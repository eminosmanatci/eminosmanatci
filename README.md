## 🚀 Featured Projects

### 📊 [InsightFlow — AI-Powered Enterprise Analytics Platform](https://github.com/eminosmanatci/InsightFlow)
Multi-tenant analytics platform that turns raw CSV sales data into business insights.
- FastAPI + PostgreSQL backend with **JWT auth, RBAC and tenant-level data isolation**
- CSV ingestion with validation and duplicate detection; background processing with **Celery + Redis**
- **LLM-powered executive summaries** and business insights
- ✅ **62 backend tests, ~95% coverage**, CI with GitHub Actions, fully Dockerized

`FastAPI` `PostgreSQL` `SQLAlchemy` `Alembic` `Celery` `Redis` `Docker` `Pytest` `LLM`

### 🎥 [SentinelVision — AI Security Video Analytics & RAG Platform](https://github.com/eminosmanatci/SentinelVision)
Video analytics platform that detects people and objects in footage and answers questions about it in natural language.
- Object and person detection with **YOLOv8**
- **RAG pipeline** over detection events with **PostgreSQL + pgvector** and LLM integration
- Async FastAPI backend; long-running video analysis with **Celery + Redis**

`FastAPI` `YOLOv8` `pgvector` `RAG` `Async SQLAlchemy` `Alembic` `Celery` `Redis`

### 🐄 [AgroByte Vision — Smart Farm Management](https://github.com/eminosmanatci/AgroByte-Vision) · *TEKNOFEST 2025 Finalist*
Real-time computer vision system for smart farms, running on Raspberry Pi.
- Cow detection, **ID-based multi-object tracking** and behavior analysis (standing, lying, feeding)
- Fire & smoke early warning, face recognition for access control, automated hay bale counting
- My role: AI developer — built, trained and deployed the detection and tracking models

`YOLOv8` `OpenCV` `PyTorch` `FaceNet` `FastAPI` `PostgreSQL` `Raspberry Pi`

### 🌱 [AgriLens — AI-Powered Plant Disease Assistant](https://github.com/eminosmanatci/AgriLens)
End-to-end mobile app that identifies plant diseases from photos and gives AI-generated treatment recommendations.
- Image classification model served through a FastAPI backend
- Flutter mobile client
- LLM-based agricultural recommendations

`Image Classification` `FastAPI` `Flutter` `LLM`
