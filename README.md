- FastAPI and PostgreSQL backend
- Organization and role-based authorization
- Background data processing with Celery and Redis
- SQLAlchemy and Alembic database management
- Docker-based development environment
- Automated testing with Pytest

### SentinelVision — Video Analytics Platform

A backend platform for uploading, processing and analyzing video content using computer vision and AI technologies.

- Asynchronous video processing
- Object detection and detection storage
- FastAPI REST services
- PostgreSQL and vector-based data architecture
- RAG-powered interaction with analysis results

A computer vision system developed for smart farm management and agricultural automation.

- Object detection with YOLO
- Multi-object tracking and activity analysis

- Livestock behavior analysis
- Raspberry Pi and backend integration
- TEKNOFEST 2025 Finalist

An end-to-end mobile application for identifying plant diseases and generating AI-powered recommendations.

- Image classification
- FastAPI backend
- Flutter mobile application
- LLM-based agricultural recommendations
- Model and API integration
